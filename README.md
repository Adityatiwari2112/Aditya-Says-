# 🎮 Aditya Says

A fun and interactive memory game inspired by the classic **Simon Says** game. Test your memory by remembering an increasingly long sequence of colored blocks.

## 📖 About the Game

**Aditya Says** is a browser-based memory game where players must remember and repeat a sequence of randomly highlighted colors.

The game starts with a single color flashing. After every successful round, a new random color is added to the sequence. Your goal is to correctly repeat the **entire pattern from the beginning**.

The game continues until you make a mistake.

---

## 🎯 How to Play

1. Press any key to start the game.
2. One of the four colored blocks will blink.
3. Click the same colored block.
4. In the next level, another random color is added.
5. Repeat the complete sequence in the correct order.
6. Continue memorizing the growing pattern.
7. The game ends when you click the wrong color.

## 🎮 Game Rules

- Memorize the flashing color sequence.
- Repeat the sequence by clicking the colored blocks.
- Each level adds one new random color.
- The sequence always starts from the beginning.
- Clicking the wrong color ends the game.
- Try to achieve the highest level possible!
